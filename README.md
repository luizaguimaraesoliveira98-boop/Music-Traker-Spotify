# Spotify Music Analysis

Projeto de análise de dados musicais utilizando BigQuery, SQL, Spark e Looker Studio.

## Objetivo
Analisar características musicais, popularidade, artistas e gêneros presentes em músicas do Spotify.

## Ferramentas utilizadas
- Google BigQuery
- SQL
- Apache Spark
- Looker Studio
- Google Colab

## Dataset
Spotify Tracks Dataset (Kaggle)

## Visualizações
- KPI de músicas
- Top artistas
- Músicas explícitas
- Popularidade por gênero
- Tabela detalhada

## Insights
- Identificação dos artistas com maior quantidade de músicas
- Gêneros com maior popularidade média
- Distribuição de músicas explícitas
- Características musicais como energia e danceability

_Link dos dados_: https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset?utm_source=chatgpt.com
